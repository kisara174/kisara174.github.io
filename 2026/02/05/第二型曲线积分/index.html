第二型曲线积分

这份笔记旨在为你提供一个从底层逻辑到高阶公式的完整知识框架。它比之前的版本更深入，涵盖了定义、计算细节、判定法则以及应试技巧。

📚 第二型积分

第一部分：定义与本质

1. 核心定义

  • 第二型曲线积分（对坐标）：计算向量场 $\vec{F}$ 沿有向曲线 $L$ 所做的功。
    • 形式：$\int_L Pdx + Qdy + Rdz$
  • 第二型曲面积分（对坐标）：计算向量场 $\vec{v}$ 穿过有向曲面 $\Sigma$ 的流量（通量）。
    • 形式：$\iint_\Sigma P dydz + Q dzdx + R dxdy$

2. 与第一型积分的本质区别（重要！）

维度 第一型（线/面） 第二型（线/面）
几何对象 无向（像一根没有箭头的绳子） 有向（像一条单行道或有正反的网）
物理对应 质量、重心、表面积 功、通量
元素性质 $ds, dS$ 永远为正，代表长度/面积 $dx, dy, dz$ 可正可负，代表投影分量
反向结果 不变：$\int_L = \int_{-L}$ 变号：$\int_L = -\int_{-L}$

第二部分：计算方法（核心套路）

1. 曲线积分：化为一元定积分

步骤：一代、二求、三定限。

  • 代入： 将曲线方程（如 $y=y(x)$ 或参数方程 $x=x(t), y=y(t)$）代入 $P, Q$。
  • 求导： 求出 $dx = x’(t)dt, dy = y’(t)dt$。
  • 定限： 积分下限必为起点对应的参数，上限必为终点对应的参数。
    • 注意： 即便起点参数比终点参数大（如 $2\pi$ 到 $0$），也要按此顺序。

2. 曲面积分：化为二重积分（投影法）

以 $\iint_\Sigma R(x,y,z) dxdy$ 为例：

  1. 投影： 将曲面 $\Sigma$ 投影到 $xy$ 平面，得到区域 $D_{xy}$。
  2. 代入： 把曲面方程 $z=z(x,y)$ 代入 $R$ 中。
  3. 定号（最易错点）：
    • 如果 $\Sigma$ 的方向取上侧（法向量与 $z$ 轴正向夹角为锐角），前面加 $+$。
    • 如果 $\Sigma$ 的方向取下侧，前面加 $-$。
    • （同理，前/后侧对应 $dydz$，左/右侧对应 $dzdx$）。

第三部分：路径无关性（高频考点）

1. 四个等价条件

在一个单连通区域（内部没有洞的区域）内，以下四个条件等价：

  1. $\int_L Pdx + Qdy$ 与路径无关。
  2. 沿任意闭合曲线 $C$ 的积分 $\oint_C Pdx + Qdy = 0$。
  3. 交叉偏导相等： $\frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y}$。
  4. 存在势函数 $u(x,y)$ 使得 $du = Pdx + Qdy$。

2. 技巧：如何简化计算？

如果判定路径无关，你可以：

  • 折线法： 将复杂的曲线 $L$ 换成平行于坐标轴的折线 $A(x_1, y_1) \to C(x_2, y_1) \to B(x_2, y_2)$。
    • 在 $AC$ 段，$dy=0$；在 $CB$ 段，$dx=0$。计算量瞬间减少 80%。
  • 势函数法： 积分结果直接等于 $u(B) - u(A)$。

第四部分：三大核心公式（跨维度的桥梁）

1. 格林公式 (Green’s Theorem) —— 线变面

  • 公式： $\oint_L Pdx + Qdy = \iint_D (\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}) dxdy$
  • 适用： 平面闭合曲线。
  • 方向： $L$ 必须是正向（人沿曲线走，左手边永远是区域 $D$；通常是逆时针）。

2. 高斯公式 (Gauss’s Theorem) —— 面变体

  • 公式： $\oiint_\Sigma P dydz + Q dzdx + R dxdy = \iiint_V (\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}) dV$
  • 适用： 空间封闭曲面。
  • 方向： $\Sigma$ 必须取外侧。如果是内侧，结果记得加负号。

3. 斯托克斯公式 (Stokes’ Theorem) —— 线变面

  • 适用： 空间曲线与它覆盖的曲面。
  • 逻辑： 曲线的功 = 穿过曲面的旋度通量。

第五部分：初学者常见“陷阱”总结

  1. 奇点（洞）陷阱：

    • 如果题目给出的 $P, Q$ 在某个点（通常是原点）分母为 0，那么即便 $\frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y}$，沿包含原点的闭合回路积分也不一定为 0！
    • 应对： 这种题通常需要用“挖洞法”，在奇点周围补一个小圆。

  2. “开口”变“闭合”：

    • 格林公式和高斯公式都要求是封闭的线/面。如果题目给的线是开的，你需要手动补上一条线，算出闭合积分后，再减去你补的那段积分。

  3. 二重积分 vs 第二型曲面积分：

    • 二重积分是算面积底下的体积，结果永远反映大小。
    • 第二型曲面积分算的是穿透量，一定要根据“侧”来判断符号。

  4. 斯托克斯公式的手性规则：

    • 使用右手螺旋法则：大拇指指向曲面法向，四指指向曲线绕行方向。如果题目方向反了，结果加负号。
