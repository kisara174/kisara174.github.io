# 📖 大学物理复习笔记：质点运动学的描述

## 一、 描述运动的基础框架
1.  **质点模型**：忽略形状大小，只考虑质量（条件：物体尺寸 $\ll$ 运动空间，或做平动）。
2.  **参考系与坐标系**：运动具有相对性，必须选定参考系。常用直角坐标系 $(x,y,z)$ 或自然坐标系 $(\tau, n)$。
3.  **运动方程**：$\vec{r}(t) = x(t)\vec{i} + y(t)\vec{j} + z(t)\vec{k}$。
    *   *技巧*：消去参数 $t$ 即可得到**轨迹方程**。

## 二、 核心物理量（微积分定义）
1.  **位矢 $\vec{r}$**：从原点指向质点。
2.  **位移 $\Delta \vec{r}$**：$\Delta \vec{r} = \vec{r}(t+\Delta t) - \vec{r}(t)$（矢量，初位置指向末位置）。
    *   *注意*：位移模 $|\Delta \vec{r}|$ $\neq$ 路程 $\Delta s$（仅在单向直线运动且 $\Delta t \to 0$ 时近似相等）。
3.  **速度 $\vec{v}$**：$\vec{v} = \frac{d\vec{r}}{dt}$。方向为轨迹切线指向。
    *   **速率**：$v = |\vec{v}| = \frac{ds}{dt}$。
4.  **加速度 $\vec{a}$**：$\vec{a} = \frac{d\vec{v}}{dt} = \frac{d^2\vec{r}}{dt^2}$。

---

## 三、 自然坐标系与加速度分解（重难点）
当质点沿曲线运动时，在轨迹上任一点建立切向（$\tau$）和法向（$n$）坐标：

1.  **切向加速度 $a_\tau$**：
    *   公式：$a_\tau = \frac{dv}{dt}$
    *   意义：描述**速度大小（速率）**的变化快慢。
2.  **法向加速度 $a_n$**：
    *   公式：$a_n = \frac{v^2}{\rho}$ （$\rho$ 为曲率半径）
    *   意义：描述**速度方向**的变化快慢。
3.  **总加速度 $\vec{a}$**：
    *   $\vec{a} = \vec{a}_\tau + \vec{a}_n$
    *   大小：$a = \sqrt{a_\tau^2 + a_n^2}$

---

## 四、 圆周运动：线量与角量的深度整合
圆周运动是曲线运动的特例（半径 $\rho = R$ 恒定）。

### 1. 物理量对应桥梁
线量（沿圆弧）与角量（绕圆心）通过半径 $R$ 紧密联系：

| 物理意义 | 线量 (Linear) | 角量 (Angular) | 关系式 ($R$为常数) |
| :--- | :--- | :--- | :--- |
| **位置/位移** | 弧长 $s$ | 角度 $\theta$ | $s = R\theta$ |
| **速度** | 线速率 $v$ | 角速度 $\omega = \frac{d\theta}{dt}$ | $v = R\omega$ |
| **加速度变化率** | **切向加速度 $a_\tau$** | **角加速度 $\alpha = \frac{d\omega}{dt}$** | **$a_\tau = R\alpha$** |

### 2. $a_\tau$、$a_n$ 与 $\alpha$ 的核心关系解析
这是本章最容易混淆的地方，请务必掌握：

*   **$a_\tau$（切向）与 $\alpha$（角加）的“父子关系”**：
    *   由于 $v = R\omega$，对时间求导得：$\frac{dv}{dt} = R\frac{d\omega}{dt}$。
    *   结论：**$a_\tau = R\alpha$**。
    *   *理解*：转得越来越快（$\alpha$），轨迹上的点就跑得越来越快（$a_\tau$）。

*   **$a_n$（法向）与 $\omega$（角速）的“平方关系”**：
    *   代入 $v=R\omega$ 到 $a_n = \frac{v^2}{R}$ 中。
    *   结论：**$a_n = R\omega^2$**。
    *   *理解*：只要在转（$\omega \neq 0$），就一定有法向加速度。

*   **总加速度的角量表示**：
    *   $a = \sqrt{a_\tau^2 + a_n^2} = \sqrt{(R\alpha)^2 + (R\omega^2)^2} = R\sqrt{\alpha^2 + \omega^4}$

### 3. 运动状态判别
*   若 $\alpha = 0 \Rightarrow a_\tau = 0$：**匀速圆周运动**（只有 $a_n$，加速度指向圆心）。
*   若 $\alpha =$ 常数 $\Rightarrow a_\tau =$ 常数：**匀变速圆周运动**。
*   若 $\alpha$ 随 $t$ 变：**变加速圆周运动**。

## 五、 运动学的两类典型问题
1.  **第一类问题（求导）**：
    *   已知：运动方程 $\vec{r}(t)$。
    *   过程：$\vec{r}(t) \xrightarrow{\text{求导}} \vec{v}(t) \xrightarrow{\text{求导}} \vec{a}(t)$。
2.  **第二类问题（积分）**：
    *   已知：加速度 $\vec{a}(t)$ 及初值条件（$t_0, \vec{v}_0, \vec{r}_0$）。
    *   过程：$\vec{a}(t) \xrightarrow{\text{积分}} \vec{v}(t) \xrightarrow{\text{积分}} \vec{r}(t)$。
    *   *关键*：**分离变量**，注意积分上下限。

---

## 六、 易错陷阱总结
1.  **矢量性**：加速度 $\vec{a}$ 是 $\vec{v}$ 的变化，包含大小和方向。匀速圆周运动的 $\vec{a}$ **不为零**！
2.  **三个容易混淆的量**：
    *   $\frac{dv}{dt}$：即 $a_\tau$，速率的变化率。
    *   $\frac{d|\vec{r}|}{dt}$：向径长度的变化率（不等于速率）。
    *   $|\frac{d\vec{r}}{dt}|$：即速率 $v$。
3.  **相对运动**：
    *   $\vec{v}_{绝对} = \vec{v}_{相对} + \vec{v}_{牵连}$
    *   解题技巧：画出矢量三角形，利用余弦定理或分量法求解。
